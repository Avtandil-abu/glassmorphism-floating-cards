# Glassmorphism Floating Cards

Stunning interactive glassmorphism card components built with React & Three.js.

## ✨ Features

- 🪟 Glass morphism cards with real depth and blur
- 🖱️ Mouse tilt effect — cards react to cursor position
- 🌊 Floating animation — each card floats independently
- ⭐ Parallax star field background
- 💧 Liquid text effect on hover
- 📱 Mobile touch support

## 🚀 Getting Started

### Installation

```bash
git clone https://github.com/yourusername/your-repo-name
cd your-repo-name
npm install
npm start
```

### Build for Production

```bash
npm run build
```

## 🛠️ Tech Stack

- React
- Three.js
- React Three Fiber
- React Three Drei

## 🎨 Customization

| Parameter | Location | Description |
|-----------|----------|-------------|
| Card color | `accent: "160, 68, 255"` | RGB accent color per card |
| Blur amount | `blur(40px)` | Glass blur intensity |
| Float speed | `floatDurations` | Animation duration per card |
| Star count | `count={900}` | Number of background stars |
| Background | `background:` in App style | Gradient colors |

## 📦 Dependencies

```bash
npm install three @react-three/fiber @react-three/drei
```
